# Some single-cell transcriptomic analyses

Data from scRNA-seq of a single patient using paired tumor/normal tissues from [GSE241895](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE241895). 

## Some highlights from the notebook:
- Scanpy/Anndata to combine metadata seamlessly with counts
- Various scanpy packages used when normalizing -> clustering -> subsetting data
- Exploration of HVGs vs. DEGs
